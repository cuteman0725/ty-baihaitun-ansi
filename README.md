## 兩個踩過的坑（做 PTT ANSI 圖的人可以參考）

**1. PTT「一頁看得到 23 行」，但「翻一頁只前進 22 行」**

這是兩個不同的數字，混在一起就會差一行：

| 問題 | 答案 |
|---|---|
| 一頁**看得到**幾行 | **23**（終端機 24 列，最下面一行是狀態列） |
| 按一次 PageDown **前進**幾行 | **22** |

差額是 pmore 的重疊行——**上一頁的最後一行會變成下一頁的第一行**。
實貼文章的行號可以直接印證：第 1 頁 `01~22`、第 2 頁 `22~44`、第 3 頁 `44~66`……每頁起點差 22。

所以正確做法不是「每格做 23 行」，而是：

```
每格 = 21 行內容 ＋ 1 行空白 = 22 行
      └ 空白同時是本格結尾與下一格的頂端，重疊在空白處看不出來
讀者每頁看到 = 空白 ＋ 21 行內容 ＋ 空白 = 23 行  ✓
```

第二個偏移來源：文章最前面固定 **4 行**（作者／標題／時間＋分隔線），
所以 `make_ptt.py` 放一張 **18 行封面卡**（4 ＋ 18 ＝ 22 ＝ 剛好第一頁），
第一格才會從第二頁頂端開始。

**2. 全形寬度不能用 `unicodedata.east_asian_width()` 判斷**

`◎ ○ ↑ ← ╲ ╱ ─ │ ┌ ┐ ① ② 皿 ω ～ ×` 在 Unicode 是 **Ambiguous(A)**，
很多程式會誤判成 1 欄——但在 Big5 站台它們是**雙位元組、佔 2 欄**。正確作法：

```python
def wide(ch):
    if ord(ch) < 128:
        return False
    return len(ch.encode('cp950')) == 2   # Big5 雙位元組 = 全形 = 2 欄
```

用錯的話整張圖右半邊會全部位移一欄，對話框的 `┌─┐` 最先看得出來。

順帶一提，`✕`(U+2715) **不在** Big5，要用 `×`(U+00D7)；`①②③ ╭╮╰╯ ω 皿` 都在。
